# ⚔️ 勇者冒险 — 游戏说明手册

---

## 🎮 游戏简介

**勇者冒险** 是一款纯网页 2D 横版闯关游戏，浏览器打开即玩，无需下载安装。

你扮演一位勇者，穿越 5 个关卡，消灭怪物、收集钥匙、击败 Boss，最终通关魔王城堡！

---

## 🎯 游戏目标

每关需要完成三个条件才能通过传送门进入下一关：

1. 🔑 **收集钥匙** — 先找到关卡中的金钥匙
2. ⚔️ **消灭所有怪物** — 一个都不能留
3. 🏁 **走到传送门** — 地图最右侧的绿色发光门

---

## 🕹️ 操作方式

### 电脑键盘

| 按键 | 功能 |
|------|------|
| `←` `→` 方向键 | 左右移动 |
| `↑` 方向键 | 跳跃 |
| `空格键` | 攻击 |
| `S` 键 | 手动存档 |
| `ESC` 键 | 暂停 / 继续 |
| `Q` 键 | 返回大厅 |

### 手机触屏

屏幕底部自动显示虚拟按钮：
- **方向键** — 移动和跳跃
- **⚔️ 攻击** — 攻击怪物
- **💾 存档** — 保存进度
- **⏯️ 暂停** — 暂停游戏

## 👹 怪物图鉴

| 类型 | 外观 | 特点 | 应对策略 |
|------|------|------|----------|
| 🔴 普通怪 | 红色方块 | 均衡型 | 正面攻击即可 |
| 🟡 快速怪 | 黄色小方块 | 移动快、血量低 | 预判走位，提前攻击 |
| 🟣 坦克怪 | 紫色大方块 | 速度慢、血量高 | 走位风筝，多打几下 |

## 💎 道具说明

| 道具 | 图标 | 效果 |
|------|------|------|
| 🔑 钥匙 | 金色球体 | **必须收集**才能通过传送门 |
| 💚 生命药水 | 红色球体 | 恢复 30 HP |
| ⚡ 攻击强化 | 金色球体 | +10 攻击力，持续 30 秒 |

## 💾 存档系统

- 每个账号拥有 **3 个独立存档档位**
- **自动存档**：每 30 秒 + 通关后自动保存
- **手动存档**：按 `S` 键或点 💾 按钮
- 死亡后存档自动恢复到满血状态
- 数据库持久化，重启不丢失

---

## 🏆 通关技巧

1. **先找钥匙** — 每关钥匙位置不同，注意观察金色闪光
2. **善用跳跃** — 可以跳上平台捡道具、翻越墙壁
3. **逐个击破** — 不要同时面对多个怪物，引开单个消灭
4. **利用道具** — 攻击强化能让你伤害翻倍
5. **注意血量** — 死亡后需重新开始当前关卡

## ❓ 常见问题

**Q: 走到传送门没反应？**
A: 检查是否满足三个条件：① 捡到钥匙 ② 消灭所有怪物 ③ 实际碰到传送门方块

**Q: 怪物穿墙了？**
A: 怪物受墙壁碰撞限制，但它们会追击你。利用墙壁卡位可以风筝怪物。

**Q: 道具不见了？**
A: 道具拾取一次后永久消失。如果要重置，需要新建存档。

**Q: 手机能玩吗？**
A: 完全支持！浏览器打开即可，自动显示触屏虚拟按键。
