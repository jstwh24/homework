# Vim宏批量生成ssh命令操作文档
## 需求说明
生成 `10.64.198.1 ~ 10.64.198.255` 全部ssh命令，分组规则：
- IP 1~50 输出 `> 1.log`
- IP 51~100 输出 `> 2.log`
- IP 101~150 输出 `> 3.log`
- IP 151~200 输出 `> 4.log`
- IP 201~250 输出 `> 5.log`
- IP 251~255 输出 `> 6.log`

## 前置知识点
1. `<C-a>` 不是输入字母C、a，是**键盘组合键 Ctrl + a**，作用：光标下数字自增1
2. 普通模式单独按 `c` 会进入编辑插入模式，录制宏全程不要单独按c
3. 宏语法：`qa` 开始录制存入寄存器a；`q` 结束录制；`N@a` 执行N次宏

## 方案一：Vim宏录制实现（幻灯片作业要求方法）
### 步骤1：写入首行模板
打开Vim，按 `i` 进入插入模式输入，输完按 `Esc` 切回普通模式：
```
ssh root@10.64.198.1 > 1.log
```

### 步骤2：完整录制宏（一步一步严格操作）
1. `qa` 回车：开启宏录制，所有操作存入寄存器a
2. `yy`：复制当前整行
3. `p`：在当前行下方粘贴新一行
4. `$F.`：跳到行尾，反向查找`.`，光标精准落在IP末尾数字上
5. `Ctrl + a`：IP末尾数字+1（此时光标在数字上，不会误进插入模式）
6. `$T `：反向跳到日志文件名的数字位置
7. 输入命令（自动切换日志编号）：
   ```vim
   :if expand('<cword>')%50==0 | <C-a> | endif
   ```
   语句中 `<C-a>` 同样按 `Ctrl + a`，不是输入字符
   输完按回车执行
8. `0`：光标跳回行首，准备下一轮循环
9. `q`：结束宏录制

### 步骤3：批量执行宏生成剩余254行
当前只有1行，需要再生成254行，普通模式输入：
```
254@a
```
执行完成后自动生成1~255全部ssh命令，格式与作业完全匹配。
